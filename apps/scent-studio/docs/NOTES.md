## 테스트 실행 시간
- `bash tests/run.sh` 전체 약 4분(실패 상태: 승인 테스트마다 5초씩 기다림). 훅 제한 5분에 가깝다.
  화면을 만들면 기다리는 시간이 줄어든다. M4 뒤에 다시 재고, 5분을 넘으면 Gradle 설정·테스트 묶음부터 손본다.

## 고친 것과 이유
- JDK 25에서 Robolectric이 JDK 내부(FileDescriptor, jdk.internal.access)에 접근하지 못해 40개가 환경 탓으로 실패했다
  → `app/build.gradle.kts` 테스트 JVM 옵션에 `--add-opens`·`--add-exports`·`--enable-native-access`를 넣었다(테스트 준비 코드, 앱 코드 아님).
- Python과 Java의 동점 처리: "점수 차 1e-9 이하는 같다"를 그대로 비교 함수로 만들면 Java 정렬이 깨질 수 있어서 `round(점수×1e9)`로 정렬한다(design.md 8-5절).
- 같은 노트를 한 조합에 두 번 넣는 경우 Python dict와 Java의 합계가 달라질 수 있어 규칙으로 막았다(DUPLICATE_NOTE).

## 2026-10-31 4단계 단계 1: Expo 뼈대 + 승인 목록 Playwright 테스트
- 버전: Expo SDK 58.0.22, React Native 0.88.1, React 19.3, Expo Router 58, NativeWind 4.2.7 + Tailwind 3.4, TypeScript 6.0, Playwright 1.64, Vitest 5.0.5 (Node 26). 앱 이름·ID는 `app/app.json`.
- **승인 목록 1/41** (A1 통과). 나머지 40개는 화면(단계 5)이 없어 "○○가 화면에 없음"으로 실패한다(정상). 실행: `cd app && npx playwright test` (빌드 포함 약 1분).
- 테스트 준비 코드(검사 내용 아님)에서 정한 것:
  - 웹으로 내보낸 앱(`dist-test/`, `tests/acceptance/build-web.mjs`)을 가짜 서버 주소·가짜 로그인·기록 전송 200ms로 빌드해 크롬에서 돌린다. 예전 Kotlin의 `AppConfig` override 자리.
  - 가짜 서버는 `page.route`로 가로챈다(`harness/fakeUserServer.ts`, 예전 FakeUserServer.kt와 같은 API). 가짜 카탈로그는 `**/catalog.json.gz` 요청에 `tests/fixtures/test_catalog.json.gz`를 그대로 준다.
  - 로그인 흉내: 앱이 `authMode 'fake'`일 때 저장소 열쇠 `perfumerlab.fakeAuthSession`(`src/auth/fakeAuthKey.ts`)에 로그인 상태를 둔다. "로그인된 상태로 시작"은 이 값을 미리 넣는 것.
  - 앱 껐다 켜기(C2·E1) = 브라우저 탭을 닫고 새 탭으로 다시 열기(기기 저장소만 남음).
  - 화면 크기: 기본은 큰 폰 412×915 하나로 돌리고, 작은 폰 360×640·PC 1280×800·다크는 그 테스트 안에서 바꾼다(A1·A7·H1·H5). 41개를 크기마다 세 번 돌리면 훅 5분을 넘기 때문.
  - **글자 200%(H2) = 브라우저 확대 200%**: 웹에는 폰처럼 "글자만 키우기"가 없어서, 작은 폰(360×640)을 200%로 확대한 것과 같은 180×320 크기로 연다. 폰 앱의 글자 크기 설정은 6단계 폰 확인에서 본다.
  - E2(인터넷 없이)는 앱을 연 뒤 브라우저 자체를 오프라인으로 바꾼다(가짜 서버만 끊는 것보다 엄격). 웹에서 이게 통과하려면 화면 조각·카탈로그를 미리 받아 두어야 해서 단계 6의 서비스 워커가 필요할 수 있다.
  - B6의 상세 화면 문구는 상세 패널 안에서만 찾는다(PC에서는 추천 목록과 상세가 함께 보여서 목록의 문구로 잘못 통과하지 않게).
  - A1(폰: 탭이 화면 아래 / PC: 왼쪽에 위아래로), A7(폰: 카드가 화면 아래에 붙음 / PC: 목록 오른쪽), H5(상세가 목록 오른쪽)는 위치를 상자 좌표로 확인한다.
  - 웹에서는 숨은 이전 화면이 남아 있을 수 있어서, 이름표는 "보이는 것 중 첫 번째"로 찾는다.
- H1이 뼈대에서 진짜 문제를 하나 잡았다: 기본 하단 탭 글자(10px)가 높이 10px 상자에 들어가 한글 위아래가 약 3px 잘린다. 디자인·화면 단계에서 탭을 새로 만들며 고친다.
