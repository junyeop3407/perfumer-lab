# 엔진 v8 등급 기준값 규칙 (10단계)

> 2026-11-05 사장 결정. **기준값을 계산하기 전에 적고 커밋한다.** 결과를 본 뒤 바꾸지 않는다.

## 기준값 계산: (b′)
- 무작위 조합 500개: 실제 향수에서 층마다 노트를 하나씩 뽑고, 강도는 중간(`engine_v8_trial.random_blends`).
- v8 카탈로그의 실제 엔진(`engine_ref`)으로 조합마다 Top 10의 유사도를 모은다.
- **상위 10% 값 = 매우 비슷, 상위 40% 값 = 비슷.** 소수 셋째 자리로 반올림해 쓴다.
- **채택하는 값은 시드 20261104의 값이다.** 시드 20261105로 같은 계산을 해서 차이를 보고한다(안정성 확인). 차이는 보고만 하고 평균 내거나 값을 고르지 않는다.
- 추정치 향수에도 같은 기준값을 적용한다.

## 확인 표 (시드 20261105 조합은 기준값 계산과 분리된 확인용)
- 지금 임시값 0.87/0.81과 새 값을 나란히 놓고 비교한다. `engine_v8_trial.md` ① 표와 같은 칸이다.
- **임시값 → 새 값일 때 실제 추천 Top 10의 등급 분포.** 비교 24조합과 무작위 500조합으로 낸다.
- 등급 분포를 강도가 실제 값인 향수와 추정 값인 향수로 나눠 본다.

## 검증: 눈 평가 점수
- 눈 평가 점수는 **검증에만 쓴다.** 점수에 맞춰 기준값을 조정하지 않는다.
- 평가 15개의 향수 75개(참고 3개 제외)를 새 기준값으로 등급을 나눠 등급별 평균 점수를 낸다. 95% 구간은 조합 단위로 낸다. 기본 10개와 구르망은 따로 보여 준다.

### 통과 조건 (둘 다, 평가 75개 전체 기준)
1. **순서 조건 (핵심 검증):** 평균 점수가 매우 비슷 > 비슷 > 참고.
   - 향수가 5개 미만인 등급은 순서 판정에서 빼고 숫자만 보고한다.
   - 판정할 등급이 2개 미만이면 순서를 볼 수 없으므로 통과가 아니다.
2. **매우 비슷 평균 4.0 이상.** 전체 평균이 4.24라 쉬운 기준이고, 핵심 검증은 순서 조건이다. 매우 비슷이 5개 미만이면 이 조건을 판정할 수 없으므로 통과가 아니다.

## 결정
- **통과하면:** `engine_ref.py`와 `params.ts`의 값을 바꾸고 골든 파일과 문서를 갱신한다. 유사도 계산과 순위는 바뀌지 않는다.
- **통과하지 못하면:** 값을 바꾸지 않고 보고한 뒤 멈춘다. 사장이 결정한다.

## 한계
- 낮은 점수가 거의 없다(1점 1개, 2점 0개). 나쁜 향수를 걸러 내는지는 거의 확인할 수 없다.
- Top 5만 평가했다. 6~10위는 검증하지 못한다.
- 점수 기준과 유사도가 모두 노트 포함을 본다. 둘이 맞아도 그만큼은 감안한다.
- 무작위 조합은 3노트·강도 중간이다. 강도를 섞은 조합은 점수 분포가 다를 수 있다.
