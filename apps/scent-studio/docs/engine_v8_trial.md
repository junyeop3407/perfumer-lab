### 왜 쏠리는가

- **어코드 벡터가 원인입니다.** 강도 있는 향수의 실제 비중은 평균 34%가 목록 5개 밖 어코드에 있는데, 5·4·3·2·1 추정치는 5개만 채웁니다. 같은 향수를 두 방식으로 재면 코사인 상위 1%가 실제 강도 0.852, 추정치 0.819입니다.
- 노트 몫은 큰 원인이 아닙니다: 노트 전부 든 향수의 몫 합 평균이 실제 0.209, 균등 추정 0.222입니다.

### 보정 방안

- **P1 추정치 보정**: 강도 있는 향수(개발 절반)로 '어코드 목록 → 전체 21개 비중'을 학습해 강도 없는 향수의 벡터를 채우고, 노트 몫도 '노트별 평균 강도'로 추정합니다. 카탈로그를 만들 때 한 번만 계산하므로 앱 계산은 그대로입니다.
- **P2 데이터 유무 정규화**: 조합마다 강도 없는 묶음의 상위 50개 평균 점수를 강도 있는 묶음에 맞춰 올립니다. 비율은 잘 맞지만 점수에 보정값이 섞입니다.
- **P3 = P1 + P2**
- **M1 연결표 수정**: Fragrantica `aromatic`을 `green` 대신 `fresh`로 연결하고 카탈로그를 다시 만듭니다(④ 참고).
- **M1 + P1**: 둘을 함께 적용합니다.
