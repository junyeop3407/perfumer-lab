# Perfumer-LAB 디자인 규칙 (DESIGN.md)

작성 2026-11-11 · 디자인팀 · 상태: **시안 검토 대기(5-0)**

> 색·컨셉·모양 원칙은 `design.md` 3절(2026-10-30 사장 결정)이 기준이다. 이 문서는 그 위에 **글꼴·크기·간격·컴포넌트**를 정한다. 둘이 다르면 design.md 3절을 따른다.
> 토큰은 `app/tailwind.config.js` 한 곳에 있다. 화면 코드는 토큰 이름만 쓴다(색 값·임의 간격 금지).
> 시안: `docs/design/mock.html`(같은 토큰으로 그린 정적 시안), 캡처 `docs/design/shots/`.
> **위치 주의:** 규칙상 이름은 `docs/DESIGN.md`지만, Windows는 대소문자를 구분하지 않아 `docs/design.md`(설계 문서)와 같은 파일이 된다. 그래서 `docs/design/DESIGN.md`에 둔다(2026-11-11).

## 1. 한 가지 강조: "조합 처방전"
- 이 앱에서 기억에 남는 것은 **하나**다. 조합 요약을 조향사의 처방전처럼 보여 준다.
  - 층(TOP · MIDDLE · BASE)마다 한 줄씩 쓴다.
  - 노트 이름은 세리프로 쓴다.
  - 강도는 짧은 세로 눈금(1~3개)과 글자(약·중·강)로 함께 나타낸다.
- 다른 화면은 조용하게 둔다: 크림 바탕, 가는 선, 넉넉한 여백. 골드는 화면마다 1~2곳만 쓴다.

## 2. 글꼴
| 역할 | 글꼴 | 라이선스 | 쓰는 곳 |
|---|---|---|---|
| 제목(세리프) | **Noto Serif KR** (500·600) | OFL | 화면 제목, 향수 이름, 처방전의 노트 이름 |
| 본문(고딕) | **Pretendard** (400·500·600) | OFL | 본문, 버튼, 라벨, 숫자 |

- 숫자는 Pretendard의 고정폭 숫자(`tabular-nums`)로 쓴다. 점수·%가 줄 맞춰 보이게 하기 위해서다.
- 영문 층 라벨(TOP · MIDDLE · BASE)만 대문자에 넓은 자간(0.12em)을 쓴다(design.md 3-4). 다른 라벨은 대문자로 쓰지 않는다.
- 앱에는 글꼴 파일을 넣는다(`expo-font`). 웹은 같은 파일을 쓴다. 굵기는 표에 있는 것만 넣는다.

## 3. 글자 크기 (dp = 웹 px, 줄 높이는 8의 배수 근처)
| 토큰 | 크기 / 줄 높이 | 굵기 | 글꼴 | 쓰는 곳 |
|---|---|---|---|---|
| `display` | 28 / 36 | 600 | 세리프 | 화면 맨 위 제목(홈, 요약) |
| `title` | 22 / 30 | 600 | 세리프 | 향수 이름(상세), 시트 제목 |
| `headline` | 18 / 26 | 600 | 고딕 | 절 제목, 카드 안 향수 이름 |
| `body` | 16 / 24 | 400 | 고딕 | 본문, 목록 |
| `label` | 14 / 20 | 500 | 고딕 | 버튼, 칩, 탭, 입력창 |
| `caption` | 12 / 16 | 400 | 고딕 | 보조 설명, 출처 (가장 작은 글자) |
| `layer` | 12 / 16 | 600, 자간 0.12em, 대문자 | 고딕 | TOP · MIDDLE · BASE만 |

- 한 줄은 폰에서 화면 폭, PC에서 **최대 640px**(본문 약 40자)이다.
- 글자 크기 200%: 모든 글자는 시스템 배율을 따른다(고정 크기 금지). 줄이 넘치면 내려가고, 영역은 세로로 스크롤된다. 버튼은 높이를 늘린다(잘리지 않게).

## 4. 간격과 배치
- 8dp 단위: `1`=4, `2`=8, `3`=12, `4`=16, `6`=24, `8`=32, `12`=48.
- 화면 좌우 여백은 폰 **24**(design.md 3-4)이다. 절과 절 사이는 32, 같은 절 안은 16, 줄과 줄 사이는 8이다.
- **폰(1023 이하)**: 하단 탭 4개(홈 · 향수 찾기 · 보관함 · 마이). 위에는 화면 제목이 있다.
- **PC(1024 이상)**: 하단 탭 대신 왼쪽 메뉴(폭 240)를 쓴다.
  - 본문 최대 폭은 1120이고 가운데에 둔다.
  - 목록 → 상세는 **나란히**(목록 400 + 상세 나머지) 보여 준다. 승인 H5.
- 정렬: 글자는 모두 왼쪽 정렬이다. 숫자(점수·%)는 오른쪽 정렬이다. 가운데 정렬은 빈 화면 문장 한 줄에만 쓴다.

## 5. 모양
- 모서리: 카드·시트·입력창·버튼은 **4**, 칩은 **2**. 알약 모양은 쓰지 않는다.
- 선: 1dp `border`. 그림자는 시트(아래에서 올라오는 창)에만 아주 옅게 한 단계 쓴다.
- 아이콘: Material Symbols Outlined, 굵기 300, 크기 24. 채운 아이콘은 쓰지 않는다. 선택된 탭도 선 아이콘에 글자 굵기와 밑줄로 구분한다.
- 움직임: 시트·패널은 200ms 슬라이드, 화면 전환은 150ms 페이드. "움직임 줄이기" 설정이면 없앤다.

## 6. 컴포넌트
| 이름 | 생김새 | 상태 |
|---|---|---|
| **버튼(주)** | `primary` 바탕, `onPrimary` 글자, 높이 48, 모서리 4, 라벨 크기 | 누름: `primaryHover` · 끔: `surfaceAlt` 바탕 + `textSub` 글자 · 작업 중: 글자 대신 "저장하는 중" + 막대(빙글 아이콘 없음) |
| **버튼(보조)** | 투명 바탕, 1dp `primary` 테두리, `primary` 글자, 높이 48 | 같음 |
| **글자 버튼** | 밑줄 없는 `primary` 글자, 누르는 곳 48 | 포커스: 2dp `accentStrong` 테두리 |
| **노트 칩** | 층 색(`noteTop`·`noteMiddle`·`noteBase`) 바탕, 그 위 글자색, 모서리 2, 높이 36(누르는 곳 48), 노트 이름 + 강도 눈금 | 고름: 칩 왼쪽에 체크 + 1dp 진한 테두리(색만으로 구분하지 않음) |
| **강도 표시** | 세로 눈금 3칸(2×12, 간격 2). 약=1·중=2·강=3칸이 칠해지고 바로 옆에 "약·중·강" 글자 | 화면 읽기: "레몬, 강" |
| **계열 칩** | 테두리만(1dp `border`), `text` 글자, 계열 색 없음 | 고름: `accentSoft` 바탕 + `accentStrong` 테두리 + 체크 |
| **어코드 칩** | 테두리만, `caption` 크기, 향수 카드의 상위 어코드 3개 | — |
| **어코드 막대(비교)** | 한 줄에 어코드 이름·내 조합 %·향수 % 글자를 쓰고, 그 아래 막대 두 개(6dp, 각진 끝): 내 조합 `primary`, 향수 `accent` | 화면 읽기: "시트러스, 내 조합 44퍼센트, 이 향수 38퍼센트" |
| **등급 표시** | 매우 비슷: `accent` 바탕 + `onAccent` 글자 · 비슷: 1dp `accentStrong` 테두리 + `accentStrong` 글자 · 참고: `textSub` 글자만 | 글자가 늘 함께 있다 |
| **카드** | `surface` 바탕, 1dp `border`, 모서리 4, 안쪽 16 | 누름: `surfaceAlt` |
| **입력창(검색)** | `surfaceAlt` 바탕, 높이 48, 모서리 4, 왼쪽 선 아이콘 | 포커스: 1dp `primary` 테두리 |
| **하단 탭** | `surface` 바탕, 위 1dp 선, 탭 4개(아이콘 + `label`) | 선택: `primary` 글자 + 굵게 + 아이콘 아래 2dp 선 |
| **시트(폰)/패널(PC)** | 노트 카드·확인 창. 폰은 아래에서 올라옴(위 모서리 4), PC는 오른쪽 패널 | 바깥 누르면 닫힘, 닫기 버튼 늘 있음 |
| **서버 안내 줄** | 화면 위 `accentSoft` 띠 한 줄: "서버를 깨우는 중이에요. 30초쯤 걸릴 수 있어요" + 다시 시도 | 3초 넘으면 나옴(E4) |

## 7. 네 가지 상태 (모든 화면)
- **불러오는 중**: 내용 자리에 `surfaceAlt` 막대(움직임 없음) + 한 줄 설명. 빙글 도는 아이콘은 쓰지 않는다.
- **내용 있음**: 위 규칙대로 보여 준다.
- **비어 있음**: 차분한 문장 한 줄과 버튼 하나. 예: "저장한 조합이 아직 없어요." + [새 조합 만들기]
- **오류**: 무엇이 안 됐는지와 할 일을 쓴다. 예: "인터넷 연결이 끊겨 저장하지 못했어요. 연결되면 다시 눌러 주세요." + [다시 시도]. 사과하는 말은 넣지 않는다.

## 8. 문구
- 존댓말로 짧게 쓴다. 버튼은 하는 일을 그대로 말한다: [추천 보기], [저장], [찜하기]/[찜 해제], [계정 삭제].
- 결과 알림도 같은 말을 쓴다(저장 → "저장했어요").
- 단정하지 않는다: "데이터상 유사도", "메인 테마 추정치".
- 이모지·느낌표·유행어는 쓰지 않는다.
- 데이터 출처: 실제 카탈로그는 "Parfumo · Fragrantica(Decant)"라고 쓴다. 샘플 카탈로그는 "가상 데이터"를 화면 위에 표시한다(`plan_b_portfolio.md` 1-7).

## 9. 접근성 확인 (시안·화면 모두)
- 글자 대비 AA: 토큰 표의 짝(design.md 3-2 ★)만 쓴다.
- 누르는 곳은 48 이상이다. 포커스 테두리 2dp `accentStrong`이 늘 보인다.
- 색만으로 뜻을 전하지 않는다: 선택은 체크+테두리로, 등급·강도는 글자를 함께 쓴다.
- 캡처: 라이트·다크 × 360·412·1280 × 글자 200%(design.md 3-5).
