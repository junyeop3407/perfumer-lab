# scent-studio 테스트 목록 (1차)

> 작성: QA팀 · 2026-10-30 · /build-app 3단계 결과물
> **사장 승인: 2026-10-30 승인 (40개).** 승인 대상은 이 문서의 "승인 목록" 하나뿐이다. 사장 허락 없이 고치거나 지우지 않는다.
> 이 목록이 모두 통과해야 1차가 "끝"이다.

## 어떻게 확인하나
- PC에서 자동으로 돌린다. 앱 화면을 사람처럼 누르고 글자를 읽어서 확인한다(Robolectric + Compose UI 테스트, 에뮬레이터 없음).
- **가짜 향수 데이터**(약 60개, 테스트용으로 직접 만든 것)와 **가짜 서버**를 쓴다. 그래서 결과가 매번 똑같고 인터넷이 없어도 돈다.
- 구글 로그인은 자동으로 누를 수 없어서, 테스트에서는 "로그인된 상태"를 흉내 낸다. 진짜 구글 로그인은 6단계에 사장이 실제 폰으로 확인한다(맨 아래 "사장 직접 확인").
- 아래에 나오는 노트·향수 이름은 가짜 데이터에 넣어 둘 예시다.

## 승인 목록

### A. 향 조합 만들기
| # | 이렇게 하면 | 이렇게 되어야 한다 |
|---|---|---|
| A1 | 앱을 켠다 | 하단 탭 4개(홈 · 향수 찾기 · 보관함 · 마이)가 보이고, 홈에 "새 조합 만들기"가 있다 |
| A2 | 새 조합 → 계열 "시트러스", "우디" 선택 → 다음 | 노트 선택 화면에 탑 · 미들 · 베이스 층 탭이 있고, 고른 계열의 노트가 먼저 보인다 |
| A3 | 탑에 레몬(강), 미들에 장미(중), 베이스에 샌달우드(약)를 고른다 | 노트마다 고른 강도가 표시된다 |
| A4 | 탑에 노트 3개를 고른 뒤 4번째를 누른다 | 4번째는 들어가지 않고 "층마다 3개까지 고를 수 있어요"가 보인다 |
| A5 | 검색창에 "베르가"를 친다 / "berg"를 친다 | 둘 다 "베르가못"이 나온다 |
| A6 | 목록에는 없는 드문 노트(검색 전용) 이름을 검색한다 | 검색 결과에 나오고 고를 수 있다 |
| A7 | 노트 하나를 길게 누르거나 정보 버튼을 누른다 | 아래에서 노트 카드가 올라와 한 줄 설명, 계열, 잘 어울리는 노트 3개가 보인다 |
| A8 | A3 상태에서 "조합 요약"으로 간다 | 층별로 고른 노트가 보이고, 어코드 막대마다 이름과 %가 글자로 보이며, %를 더하면 100이다 |
| A9 | 베이스를 비운 채 요약으로 간다 | "베이스가 비어 있어 잔향이 가볍게 느껴질 수 있어요" 같은 안내가 보인다 |
| A10 | 요약에서 "노트 수정"을 누른다 | 노트 선택 화면으로 돌아가고, 고른 노트가 그대로 있다 |

### B. 추천 보기
| # | 이렇게 하면 | 이렇게 되어야 한다 |
|---|---|---|
| B1 | 요약에서 "추천 보기"를 누른다 | 향수 10개가 점수 높은 순서로 나온다 |
| B2 | 추천 목록을 본다 | 향수마다 브랜드·이름, 점수와 등급(매우 비슷 / 비슷 / 참고), 공통 어코드, 일치한 노트가 보인다 |
| B3 | 한 브랜드 향수가 많은 가짜 데이터로 추천을 본다 | 10개 안에 같은 브랜드는 최대 2개다 |
| B4 | 기획서의 맹점 조합(레몬 강 + 오스만투스 중 + 샌달우드 약)으로 추천을 본다 | 1위가 가짜 데이터에 넣어 둔 "가벼운 시트러스·플로럴 향수"이고, "무거운 우디 향수"는 그보다 아래다 |
| B5 | 추천 1위를 누른다 | 향수 상세에 노트 피라미드(탑·미들·베이스), "내 조합 vs 이 향수" 어코드 비교 막대(이름과 %), 일치한 노트와 이 향수에만 있는 노트가 보인다 |
| B6 | 추천 화면과 향수 상세를 본다 | "데이터상 유사도"라는 말과 데이터 출처(Parfumo)가 보인다 |

### C. 불호 노트와 취향 (로그인 없이도)
| # | 이렇게 하면 | 이렇게 되어야 한다 |
|---|---|---|
| C1 | 로그인하지 않고 마이에서 "패출리"를 불호 노트로 정한 뒤 추천을 다시 본다 | 추천 10개 중 어느 층에도 패출리가 든 향수가 없다 |
| C2 | C1 다음 앱을 껐다 켠다 | 불호 노트 설정이 그대로 남아 있다 |
| C3 | 마이에서 선호 계열 "플로럴"을 정하고 같은 조합으로 추천을 본다 | 순위가 바뀌어, 플로럴 어코드가 강한 향수가 전보다 위로 온다 |

### D. 저장 · 찜 · 시향 피드백
| # | 이렇게 하면 | 이렇게 되어야 한다 |
|---|---|---|
| D1 | 로그인하지 않고 조합 "저장"이나 향수 "찜"을 누른다 | 로그인 화면이 나온다 |
| D2 | 로그인한 상태로 조합에 이름을 붙여 저장한다 | 보관함 "조합"에 그 이름으로 보인다 |
| D3 | 로그인한 상태로 향수를 찜한다 / 다시 눌러 찜을 푼다 | 보관함 "찜"에 생겼다가 사라진다 |
| D4 | 향수 상세에서 시향 피드백(만족도 4, 비슷했나 3, 메모)을 남긴다 | 보관함 "시향 기록"에 점수와 메모가 보인다 |
| D5 | 보관함에서 저장한 조합을 누른다 | 조합 요약이 열리고, 거기서 추천을 다시 볼 수 있다 |
| D6 | 로그인 전에 불호 노트 "패출리"를 정해 두고, 서버에는 "오크모스"가 불호로 저장된 계정으로 로그인한다 | 마이에 패출리와 오크모스가 둘 다 불호로 보인다 |

### E. 끊기지 않게
| # | 이렇게 하면 | 이렇게 되어야 한다 |
|---|---|---|
| E1 | 노트를 고르던 중 앱을 끄고(시스템이 앱을 정리한 것처럼) 다시 켠다 | 홈에 "만들던 조합 이어 하기"가 있고, 누르면 고르던 노트와 강도가 그대로다 |
| E2 | 인터넷이 끊긴 상태로 새 조합 → 요약 → 추천 → 향수 상세, 그리고 향수 검색을 한다 | 모두 된다 |
| E3 | 인터넷이 끊긴 상태로 로그인된 사용자가 저장을 누른다 | "인터넷 연결을 확인해 주세요"와 "다시 시도" 버튼이 보이고, 앱이 멈추지 않는다 |
| E4 | 서버가 3초 넘게 대답하지 않을 때 저장을 누른다 | "서버를 깨우는 중이에요" 안내가 보이고, 서버가 대답하면 저장된다 |

### F. 향수 찾기
| # | 이렇게 하면 | 이렇게 되어야 한다 |
|---|---|---|
| F1 | 향수 찾기 탭에서 향수 이름 일부 / 브랜드 이름을 친다 | 맞는 향수가 나오고, 누르면 향수 상세가 열린다 |
| F2 | 조합 없이 검색으로 연 향수 상세를 본다 | 비교 막대 없이 그 향수의 어코드와 노트 피라미드만 보인다 |

### G. 계정
| # | 이렇게 하면 | 이렇게 되어야 한다 |
|---|---|---|
| G1 | 마이에서 "계정 삭제"를 누른다 | "저장한 조합·찜·시향 기록이 모두 지워지고 되돌릴 수 없어요" 확인 창이 나온다 |
| G2 | 확인 창에서 삭제를 누른다 | 로그아웃 상태가 되고, 보관함이 비어 있다 |
| G3 | 마이를 본다 | 개인정보처리방침 링크와 웹에서 계정 삭제를 요청하는 방법 링크가 있다 |

### H. 보기 편하게 (화면 크기 · 글자 크기 · 화면 읽기)
| # | 이렇게 하면 | 이렇게 되어야 한다 |
|---|---|---|
| H1 | 작은 폰(360dp)과 큰 폰(411dp)에서 홈 · 노트 선택 · 요약 · 추천 · 상세 · 보관함 · 마이를 연다 | 글자나 버튼이 잘리거나 겹치지 않는다 (라이트·다크 모두) |
| H2 | 글자 크기를 200%로 키우고 H1의 화면들을 연다 | 내용이 잘리지 않고 스크롤로 다 볼 수 있으며, 주요 버튼을 누를 수 있다 |
| H3 | 화면 읽기(TalkBack)가 어코드 막대를 읽는다 | "시트러스 22퍼센트"처럼 이름과 숫자로 읽는다 |
| H4 | 누를 수 있는 것(버튼, 칩, 탭)의 크기를 잰다 | 모두 48dp 이상이다 |

### I. 사용 기록
| # | 이렇게 하면 | 이렇게 되어야 한다 |
|---|---|---|
| I1 | 새 조합 시작 → 요약 → 추천 보기를 한다 | 가짜 서버가 "조합 시작", "요약 보기", "추천 보기" 기록을 받는다 |
| I2 | 인터넷이 끊긴 상태에서 I1을 하고, 다시 연결한다 | 연결된 뒤 그 기록들이 서버로 간다 |

## 사장 직접 확인 (6단계, 실제 폰)
자동 테스트로는 못 하는 것이다. 6단계 QA 보고 때 확인 방법을 함께 드린다.
1. 진짜 구글 계정으로 로그인 → 저장·찜·피드백 → 앱을 지웠다 다시 깔아도 보관함이 그대로
2. 실제 서버(배포된 주소)에서 저장이 된다
3. 계정 삭제 후 같은 구글 계정으로 다시 로그인하면 빈 보관함
4. 화면 느낌이 디자인 규칙(고급스럽고 깔끔하게)과 맞는다

## 참고: QA팀이 따로 더하는 테스트 (승인 대상 아님)
- **추천 계산(엔진):** Python 참조 엔진과 Java 엔진의 결과가 같은지(가짜 데이터 기대 결과와 순위가 같고 점수 차가 1e-9 이하). 비율 합 100, 불호 노트 제외, 같은 입력 같은 결과
- **서버:** 로그인 없으면 거절, 남의 조합을 읽거나 지울 수 없음, 잘못된 입력 거절, 계정 삭제 후 데이터 없음
- **앱 부품:** 층당 3개 제한, 임시 저장 복원, 설정 합치기, 기록 대기열(최대 1,000개)
- **화면 캡처(Roborazzi):** 화면마다 라이트·다크 × 작은 폰·큰 폰 + 글자 200%. 디자인 검토 시안으로도 쓴다
- **에뮬레이터:** 새 조합 → 추천 → 상세, 앱 재시작 후 이어 하기. 6단계 보고 전에 돌린다
- **엔진 품질(실제 데이터):** 설계서 14절 합격 기준표(재현, 맹점, 블라인드 비교, 눈으로 평가, 다양성). 백엔드팀 사장 검토 때 결과를 보여 드린다
