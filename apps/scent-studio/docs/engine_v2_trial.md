**결론: Fragrantica 어코드·노트 강도를 쓰면 "사람이 비슷하다고 투표한 향수"를 찾는 성능이 올라갑니다.** 가장 좋은 시험판은 Top 50 적중률이 38.4% → 44.3%입니다(+5.9%p, 95% 구간 +2.8~+9.1). 다만 **데이터 이용 조건이 아직 확인되지 않아 엔진에는 넣지 않았습니다.**

## 시험 방법

**사람 유사 시험(새로 만듦).** 향수 p의 노트를 넣었을 때, Fragrantica 사용자가 "p와 비슷하다"고 투표한 향수가 몇 위에 오는지 봅니다.

- 정답 기준: 찬성 20표 이상, 찬성 비율 70% 이상, 같은 향수의 다른 버전은 제외
- 어느 시험판도 이 투표를 계산에 쓰지 않습니다.
- 쿼리 874개를 둘로 나눠, 개발 절반(413개)으로 후보를 고르고 남겨 둔 절반(461개)으로 한 번만 확인했습니다.
- 무작위로 고르면 Top 10 적중률은 약 0.09%입니다.

**추천 조건(남겨 둔 절반을 보기 전에 정함).** Top 50 차이의 95% 구간이 0보다 크고, 기존 기준(재현 15/20, 맹점 4/5, 브랜드 40개)을 모두 넘어야 합니다.

1위 시험판의 **"지금 일치도 × 강도 몫"은 설계서에 없고 이번 시험에서 만든 식입니다.**

```
일치도 = 지금 일치도 × (0.3 + 0.7 × √(고른 노트가 그 향수에서 차지하는 강도 몫 합))
```

설계서의 Tversky 식은 층과 노트의 희귀도를 쓰지 않습니다. 그래서 탑·미들·베이스 선택이 일치도에 반영되지 않고, 층마다 2개만 넣는 재현이 98 → 93~94로 떨어집니다. 이 식은 층·희귀도를 유지한 채 강도만 더합니다. 이 형태 하나만 시험했고 계수를 맞춰 보지는 않았습니다.

## 체크리스트 확인

| 항목 | 결과 |
|---|---|
| 데이터에 노트 강도 투표가 있나 | **Decant: 있음** (`weight` 0~100, 향수 안에서 가장 강한 노트 = 100). FragDB: 같은 종류의 값 있음, 전체 데이터는 유료($200~), 무료 샘플은 10건 |
| 투표가 있는 향수 비율 | 연결된 향수 기준 **후보의 51.7% (6,958개)**. 나머지 48%는 지금처럼 같은 몫으로 계산 |
| 투표 수 분포 | 연결 향수의 표 수 사분위 141 / 342 / 946, 70표 이상 88.9%. 단, 이 표 수는 향수 전체 평가 수이고 노트별 표 수는 데이터에 없음 |
| 5·4·3·2·1 추정치 | Fragrantica 상위 5개 실제 몫 **30.4 / 22.5 / 18.3 / 15.5 / 13.3** vs 추정치 33.3 / 26.7 / 20.0 / 13.3 / 6.7. **5위를 절반쯤 낮게 잡고 있음** |
| 어코드 순서 가정 | 같은 향수에서 Parfumo 순서와 Fragrantica 강도의 상관 중앙값 0.53, 양의 상관 81% (n=6,924). 방향은 대체로 맞음. 서로 다른 사이트의 비교라 Parfumo 자체를 대조한 것은 아님 |
| Tversky a 0.7 · b′ 0.3 비교 | 시험함. 다른 값은 안 해 봄. 상위 20개 대신 조합 12개의 Top 10 겹침만 집계 (블라인드 보호) |
| **이용 약관·라이선스** | **미해결.** Decant는 README에 "무료, 써도 된다"고만 있고 라이선스 표기를 찾지 못함. Kaggle 페이지 내용은 로그인 없이 확인하지 못함. 원본이 Fragrantica에서 수집한 데이터라 Fragrantica 약관도 별도 확인 필요. FragDB 무료 샘플은 비상업 조건(CC-BY-NC) |
| α·b·l(t) 값 확정 | **미정.** 시험에서는 α = 표 ÷ (표 + 70), b = 1 (TGSC는 가입 필요라 미사용), l = 1 |

## 이 결과의 한계

- **절대 수준은 아직 낮습니다.** 가장 좋은 시험판도 다른 브랜드 정답의 Top 50 적중률이 26.2%입니다.
- **실제 사용에 가까운 조건에서는 개선 폭이 더 작습니다.** 층마다 1개 입력은 +3.0%p이고, 구간 아래쪽이 0에 가깝습니다.
- **쿼리는 Fragrantica와 연결된 향수만 씁니다.** 후보의 48%는 강도 데이터가 없어서, 앱 전체의 효과는 이 숫자와 다를 수 있습니다.
- **"비슷하다" 투표도 사람들의 인식입니다.** 노트 구성을 보고 투표했을 수 있고, 시향 측정값은 아닙니다.
- **연결은 이름과 노트 겹침으로 했습니다.** 이름이 맞는 8,437개 중 노트가 30% 이상 겹치는 6,961개만 썼고, 잘못 연결된 향수가 일부 남아 있을 수 있습니다.
- **어코드 연결표는 이번 시험에서 정했습니다.** Fragrantica 92개 → Parfumo 21개 연결과 강도 하한 0.05는 임시값이며 사람이 검토하지 않았습니다.
- **어코드 값이 두 출처로 섞입니다.** 연결된 향수는 실제 강도, 나머지는 5·4·3·2·1입니다.
- **Top 10이 많이 바뀝니다.** 1위 시험판은 v6와 42/120개만 겹칩니다. 채택하면 블라인드 문서를 다시 만들어야 합니다.
- 개발 절반 전체 표는 스크립트를 `--only` 없이 실행하면 나옵니다. 설계서 한계별 판단에서 "개발 절반"으로 표시한 수치는 남겨 둔 절반으로 확인하지 않은 값입니다.
