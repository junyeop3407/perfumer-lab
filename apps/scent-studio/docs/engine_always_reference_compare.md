# "노트를 많이 고르면 늘 참고" — 고치는 방법 비교 (2026-11-13)

> 사장 지시 3번: **고치지 말고 비교표만.** 엔진(v8)·기준값(0.763 / 0.647)은 그대로다. 숫자는 `app/scripts/gradeVariants.check.ts`(실제 카탈로그 2026.11.05, 이 PC 약 7분)로 냈고, 그 스크립트의 "지금" 계산이 실제 엔진과 20조합 Top 10 점수까지 같은 것을 먼저 확인했다. 향수 이름은 쓰지 않는다(사장 조합 Top 5는 향수 key 해시 앞 6자리).

## 왜 늘 "참고"인가
- 사장 조합(탑 베르가못·자몽·오렌지 / 미들 버베나·튀니지안 네롤리·헬리오트로프 / 베이스 퍼 발삼·마테·건초, 강도 중) 1위: 어코드 유사도 **0.98**, 노트 일치 **0.31** → 유사도 57%.
- 노트 일치는 "고른 노트의 무게 합 중 그 향수에 있는 몫"이다. 9개를 고르면 한 향수가 그중 2~3개만 가져도 점수가 1/3쯤에 머문다. 노트 일치가 점수의 55%라 전체가 54~57%로 묶인다.
- 등급 기준값은 **노트 3개**(층마다 1개) 무작위 조합으로 만들었다(`engine_grade_v8_rules.md`). "Top 10의 약 47%가 매우 비슷"은 **손으로 고른 비교 24조합**(대부분 층마다 1개, 노트 3~4개, 많이 쓰는 노트) 기준이다.

## 추천: ㉮
- **문제가 생긴 곳(노트 5개 이상)만 고친다.** 노트 4개 이하에서는 계산이 수학적으로 지금과 똑같다(가장 무거운 4개 = 고른 노트 전부) → 3노트 화면 모양·24조합·B4·블라인드·눈 평가·기준값을 그대로 쓸 수 있다.
- 9노트 조합의 1위 "참고"가 99.8% → 11.8%로 줄고, 등급이 부풀지 않는다(매우 비슷 9.0%, 대부분 비슷).
- 대가: B7 자기 자신 찾기 1위 98.1 → 96.7%(노트 5~6개 향수에서 비슷한 향수가 함께 만점에 가까워짐), 승인 B7 테스트는 그대로 통과.
- ㉯는 등급 부풀림(24조합 Top 10의 74%가 매우 비슷)과 평가 다시 하기, ㉰는 효과 없음, ㉱는 지나침(89% 매우 비슷)과 B7 하락이 커서 추천하지 않는다.
- 남는 것: 화면 모양 **3노트** 조합도 1위 참고가 88.8%다. 앱 목록에서 계열 안 노트를 아무렇게나 고르면(무작위) 실제 향수와 덜 닮은 조합이 되기 때문으로 보인다 — 사람이 고른 24조합은 20/24가 매우 비슷. ㉮는 이것은 바꾸지 않는다.
